Профили подключения

Рекомендуем сделать
  1. 01 · Обязательно в первую очередь

    Включите разделение по приложениям: Настройки → Маршрутизация → По приложениям → Только прокси (и добавьте приложения, которые плохо работают) — так банки и обычные сервисы будут работать без сбоев.

  2. 02 · Добавьте профиль

    Скопируйте ссылку нужного профиля, отсканируйте QR-код или нажмите кнопку быстрого добавления.

  3. 03 · Оставьте автовыбор

    Убедитесь, что выбран автоматический режим по минимальной задержке (Auto / Lowest ping) — при обрыве сервер переключится сам.

  4. 04 · Если видео грузится медленно

    Откройте список серверов и запустите тест скорости (1 МБ) по всем серверам.
